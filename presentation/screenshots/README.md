# 徽州问典系统演示截图

| 顺序 | 文件 | 建议讲解内容 |
| --- | --- | --- |

| 2 | `02-tourist.png` | 游客讲解：面向游客的历史叙述、引用和景点延伸服务 |

| 5 | `05-route-map.png` | 研学路线：地图点位、顺序连线和站点列表 |
