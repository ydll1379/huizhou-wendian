## 使用说明与边界

- 手机和电脑浏览器栏中显示的是本机地址 `127.0.0.1:8000`，用于说明网页形态；它不是公网地址，外部演示前应替换为部署后的真实域名。当前素材没有伪造可扫码的二维码。
- 浏览器栏为合成的演示外框，内页截图取自本地运行的实际系统。流程图和数据图是讲解图，不是系统后台页面。
- 当前代码库没有独立的知识库管理/运营数据看板页面，因此用项目数据快照和真实引用面板说明相关能力。数据图中的数量是当前仓库快照，不代表线上流量、知识覆盖率或回答准确率。
- 审核截图使用临时演示记录采集；采集后已移除该记录，项目当前没有遗留 `data/feedback.json` 演示数据。
- 周边商户评分、价格及营业信息来自系统当前可用数据，可能缺项或变化；PPT 中应视为参考信息。
